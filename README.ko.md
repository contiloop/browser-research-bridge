# Browser Research Bridge

[English](README.md) · 한국어

Browser Research Bridge는 Mac에서 실행되는 프로그램으로, 구독 중인 뉴스 사이트처럼 내가 로그인해 둔 웹사이트를 ChatGPT가 검색하고 읽을 수 있게 해 줍니다. 내 Aside 브라우저를 그대로 쓰기 때문에 사이트에는 평소의 내 로그인으로 보이고, 비밀번호는 Mac 밖으로 나가지 않습니다. 설치와 설정 변경은 이 Mac에서만 열리는 설정 페이지에서 합니다.

## 준비물과 필요한 이유

| 준비물                                                                   | 필요한 이유                                                                                                                                              |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mac                                                                      | 이 프로그램은 macOS에서만 실행됩니다.                                                                                                                    |
| Node.js 24 이상 ([nodejs.org](https://nodejs.org/)의 LTS 설치 파일)      | 프로그램이 Node.js 위에서 돌아갑니다.                                                                                                                    |
| Aside 앱 (열어 둔 상태), 그리고 Aside 명령줄 도구 로그인 (`aside login`) | 프로그램이 내가 로그인해 둔 Aside 브라우저에서 사이트를 엽니다.                                                                                          |
| Homebrew ([brew.sh](https://brew.sh))와 OpenAI의 연결 도구               | 연결 도구(`tunnel-client`)가 ChatGPT와 이 Mac 사이의 전용 통로(터널)를 열어 둡니다. 연결 도구는 Homebrew로 설치합니다.                                   |
| 구독으로 로그인한 Claude Code 또는 Codex                                 | 새 사이트를 프로그램에 맞게 준비해 주는 AI 비서인 '사이트 추가 도우미'가 이미 쓰고 있는 Claude 또는 ChatGPT 구독으로 작동합니다. API 키는 필요 없습니다. |
| 개발자 모드를 쓸 수 있는 ChatGPT (설정 → 앱 및 커넥터 → 고급 설정)       | ChatGPT가 이 프로그램에 '커넥터'로 연결됩니다.                                                                                                           |
| OpenAI 플랫폼 계정 ([platform.openai.com](https://platform.openai.com/)) | 터널과 그 키를 거기서 만듭니다.                                                                                                                          |
| Reuters 구독 (Reuters를 쓰고 싶을 때만)                                  | Reuters가 기본으로 들어 있습니다. 대신 다른 사이트를 추가해도 됩니다.                                                                                    |

ChatGPT 화면의 메뉴 이름은 언어 설정이나 시기에 따라 위와 조금 다를 수 있습니다.

## 설치: AI에게 맡기기 (가장 쉬운 방법)

아래 문장을 Aside 안의 AI, Claude Code, 또는 Codex에 붙여 넣으세요. `<프로젝트 페이지 주소>`는 지금 보고 있는 이 GitHub 페이지의 주소(브라우저 주소창에 보이는 주소)로 바꿔 넣으세요.

```text
이 Mac에 Browser Research Bridge를 설치해 줘. <프로젝트 페이지 주소> 에 있는 INSTALL-WITH-AI.md를 읽고 한 단계씩 그대로 따라 해 줘. 내가 직접 해야 한다고 적힌 단계에서는 멈추고 나에게 물어봐. 나와는 한국어로 이야기해 줘.
```

AI는 [INSTALL-WITH-AI.md](INSTALL-WITH-AI.md)(AI용 설치 안내, 영어)를 따릅니다. Mac 비밀번호 입력, 로그인, 런타임 키 만들기, 접속 암호 만들기, ChatGPT 연결 승인처럼 나만 해야 하는 일이 나오면 AI가 멈추고 물어봅니다. 키, 비밀번호, 접속 암호는 AI에게 절대 알려 주지 마세요.

## 설치: 직접 하기

1. [nodejs.org](https://nodejs.org/)에서 Node.js 24 이상(LTS 설치 파일)을, [brew.sh](https://brew.sh)에서 Homebrew를 설치하고, Aside 앱과 Claude Code 또는 Codex도 설치합니다. Aside 명령줄 도구와 Claude Code 또는 Codex에 로그인해 둡니다.
2. '터미널' 앱을 엽니다 (Command-스페이스를 누르고 `터미널` 또는 `Terminal`을 입력한 뒤 Return). 아래 줄을 한 줄씩 붙여 넣고, 한 줄마다 Return 키를 누르세요.

   OpenAI의 연결 도구를 설치합니다 ([OpenAI 저장소](https://github.com/openai/tunnel-client)에 적힌 공식 방법):

   ```sh
   brew install openai/tools/tunnel-client
   ```

   아직 하지 않았다면 Aside 명령줄 도구에 로그인합니다 (Aside 앱이 열려 있어야 합니다):

   ```sh
   aside login
   ```

   프로그램을 내려받습니다. `<프로젝트 페이지 주소>`는 이 페이지의 주소로 바꾸세요:

   ```sh
   cd ~
   ```

   ```sh
   git clone <프로젝트 페이지 주소> browser-research-bridge
   ```

   프로그램 폴더를 Finder에서 엽니다:

   ```sh
   open ~/browser-research-bridge
   ```

3. 열린 Finder 창에서 **Open Settings.command**를 더블클릭합니다. 터미널 창이 열리고, 처음에는 다음을 차례로 합니다.
   - Node.js가 있는지 확인합니다.
   - 프로그램에 필요한 구성 요소를 설치합니다 (몇 분 걸릴 수 있습니다).
   - 설정 파일 두 개를 만듭니다.
   - 로그인할 때마다 자동으로 시작되는 '백그라운드 서비스'로 등록할지 한 번 묻습니다. 동의하면 Return 키를 누르세요.
   - 기본 브라우저에서 설정 페이지를 엽니다.

   창을 닫아도 된다는 메시지가 나오면 닫으세요.

4. 설정 페이지의 **시작하기**를 따라 하세요. 다섯 단계로 된 체크리스트이고, 각 단계는 스스로 상태를 확인합니다. 접속 암호 정하기, Aside 브라우저 준비, ChatGPT 연결하기, 사이트 추가 도우미 준비, 사이트(Reuters에 로그인하거나 원하는 사이트 추가) 순서입니다. 각 단계에서 할 일은 페이지가 설명해 줍니다.

**접속 암호**는 나만 아는 긴 비밀번호입니다. ChatGPT를 이 프로그램에 처음 연결할 때 한 번 입력하며, 다른 사람이 연결하지 못하게 막아 줍니다. 설정 페이지의 '암호 만들기' 버튼으로 만들 수 있으니, 만든 암호는 비밀번호 관리 앱 같은 안전한 곳에 보관하세요.

Claude 없이 ChatGPT 구독(Codex)만 쓴다면, 사이트를 추가하기 전에 **설정** 탭의 **도우미가 쓸 AI**에서 ‘Codex (ChatGPT 구독)’을 고르고 저장하세요.

## 평소에는

Mac에 로그인하면 프로그램이 저절로 시작되어 백그라운드에서 계속 실행됩니다. Mac이 깨어 있고 Aside 앱이 열려 있는 동안 작동합니다. 설정 페이지를 다시 열려면 내 홈 폴더의 `browser-research-bridge` 폴더에서 **Open Settings.command**를 더블클릭하세요.

## 업데이트

**Open Settings.command**를 더블클릭하세요. 새 버전이 있으면 먼저 알려 주고 묻습니다. 지금 업데이트하려면 Return 키를 누르고, 건너뛰려면 `n`을 입력한 뒤 Return 키를 누르세요 (지금 버전으로 열리고, 다음에 다시 묻습니다). 업데이트는 새 버전을 받고, 구성 요소를 설치하고, 백그라운드 서비스를 다시 시작한 뒤 설정 페이지를 엽니다. 설정, 데이터, 이 Mac에만 두는 사이트는 그대로 남습니다.

프로그램 폴더의 파일을 직접 바꾼 적이 있으면 업데이트를 건너뛰고 그 이유를 알려 줍니다. 사이트 추가 도우미가 사이트 작업을 하는 동안에는 업데이트를 미룹니다. 도우미 작업이 끝난 뒤 다시 더블클릭하세요. 구성 요소 설치에 실패하면 인터넷 연결을 확인한 뒤 다시 더블클릭하세요.

직접 업데이트하려면 (Open Settings.command도 같은 단계를 거칩니다) 터미널에 아래 줄을 한 줄씩 붙여 넣으세요:

```sh
cd ~/browser-research-bridge
```

```sh
git pull
```

```sh
npm ci
```

```sh
ops/install-launchd.sh --bridge
```

마지막 줄이 새 버전으로 백그라운드 서비스를 다시 시작합니다. 그다음 **Open Settings.command**를 더블클릭해 설정 페이지를 다시 여세요 (프로그램이 다시 시작되면 설정 페이지에 새로 로그인해야 하는데, 이 파일이 대신 해 줍니다). 설정과 추가한 사이트는 그대로 남습니다.

## 멈추기와 제거

프로그램을 멈추고 백그라운드 서비스 등록을 지우려면 (설정과 사이트는 폴더에 남습니다):

```sh
cd ~/browser-research-bridge
```

```sh
ops/install-launchd.sh --uninstall --bridge
```

나중에 다시 쓰려면 **Open Settings.command**를 더블클릭하세요. 백그라운드 서비스 등록 전에 다시 한 번 묻습니다. 완전히 지우려면 위 두 줄을 실행한 뒤 `browser-research-bridge` 폴더를 지우세요.
